Pre-requisite: Generate a Gmail App Password
1. Go to your Google Account Security settings.
2. Ensure 2-Step Verification is turned on.
3. Search for or navigate to App Passwords.
4. Create a new App Password named Ansible Syslog Alerts and copy the generated 16-character code (e.g., abcd efgh ijkl mnop).
